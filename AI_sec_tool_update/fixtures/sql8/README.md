# Bộ kiểm tra offline SQL8

Tám cảnh báo được chọn theo lượt phân tích SQL đã lưu `multi-owasp-holdout-20261115T151839Z-b04660-688bdde398e1`. Bộ kiểm tra bao gồm metadata cảnh báo từ SonarQube, snapshot Java giữ nguyên byte để kiểm tra SHA‑256 và artifact Joern đã lưu theo từng cảnh báo. Chỉ mục Joern liên kết artifact với mã cảnh báo, vùng dòng và hash nguồn.

Bộ này dùng để kiểm tra phần chuẩn bị dữ liệu. Nhãn tham chiếu, prompt, phản hồi AI và kết luận đã lưu được quản lý ở hồ sơ thực nghiệm gốc. Hướng dẫn chạy ở [README của AI_sec_tool_update](../../README.md).
